# PhoneHub — Onlayn smartfonlar va ehtiyot qismlar do'koni

Ikkinchi qo'l tekshirilgan smartfonlar, original ehtiyot qismlar va sifatli aksessuarlar savdosi uchun zamonaviy web platforma.

## Texnologiyalar

- **Frontend**: React 19, TypeScript, TanStack Start, TanStack Router
- **Styling**: Tailwind CSS v4, Lucide Icons, Sonner
- **Ma'lumotlar**: Supabase & Local reactive sync

## Ishga tushirish

Loyiha ustida ishlash uchun Node.js (v20+) va npm kerak bo'ladi.

```sh
# Bog'liqliklarni o'rnatish
npm install

# Dasturchi rejimida ishga tushirish
npm run dev

# Loyihani yig'ish (Production build)
npm run build
```
